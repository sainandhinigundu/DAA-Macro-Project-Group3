# DAA Macro Project - Group 3

## About the Project

This repository contains the programs, implementations, and academic work completed as part of the **Design and Analysis of Algorithms (DAA)** course. It covers important algorithm design techniques, problem-solving strategies, and approaches for analyzing the efficiency of algorithms.

The repository is organized into five units, covering topics from algorithm analysis and divide-and-conquer techniques to dynamic programming, backtracking, and branch-and-bound methods.

The main objective of this project is to develop a strong understanding of algorithm design, improve logical thinking, and learn how to solve computational problems efficiently.

## Project Objectives

- Understand fundamental concepts of algorithm design and analysis.
- Analyze the time and space complexity of algorithms.
- Implement different algorithmic techniques to solve computational problems.
- Compare approaches based on their efficiency and performance.
- Develop problem-solving and programming skills.
- Organize algorithm implementations topic-wise for easy reference.
- Apply theoretical concepts to practical programming problems.

## Repository Structure

### Unit 1 - Algorithm Analysis

This unit introduces the fundamental concepts of algorithms and their analysis.

Topics include:
- Introduction to algorithms
- Time complexity and space complexity
- Best-case, average-case, and worst-case analysis
- Asymptotic notations: Big O, Omega, and Theta
- Analysis of iterative and recursive algorithms
- Growth of functions and complexity comparison

### Unit 2 - Divide and Conquer

This unit focuses on solving complex problems by dividing them into smaller subproblems.

Topics include:
- Divide-and-conquer strategy
- Binary search
- Merge sort
- Quick sort
- Recurrence relations
- Analysis of recursive algorithms
- Problem-solving using divide and conquer

### Unit 3 - Dynamic Programming

This unit covers optimization techniques that solve problems by storing and reusing solutions to overlapping subproblems.

Topics include:
- Introduction to dynamic programming
- Optimal substructure
- Overlapping subproblems
- Memoization and tabulation
- Matrix chain multiplication
- Longest common subsequence
- 0/1 knapsack problem
- Multistage graph problems
- Optimal solutions using dynamic programming

### Unit 4 - Backtracking

This unit explores a systematic search technique that builds candidate solutions and abandons paths that cannot produce valid solutions.

Topics include:
- Introduction to backtracking
- State space trees
- N-Queens problem
- Sum of subsets problem
- Graph coloring
- Hamiltonian cycle problem
- Promising and non-promising nodes
- Constraint-based problem solving

### Unit 5 - Branch and Bound

This unit focuses on optimization problems using systematic exploration and bounds to eliminate unpromising candidates.

Topics include:
- Introduction to branch and bound
- State space trees
- Bounding functions
- Least-cost branch and bound
- FIFO branch and bound
- Travelling Salesperson Problem
- Assignment problem
- Knapsack problem using branch and bound
- Optimization using bounding techniques
